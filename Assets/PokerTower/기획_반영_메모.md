# 기획서 반영 메모 (Unity 프로토타입 v0.3 · 기획서 v1.3)

기획서의 [확정] 규칙은 그대로 구현했습니다. 기획서에서 "미정"인데 게임을 돌리려면 값이 필요한 항목은 **[가정]**으로 임시 결정했고, 전부 `Core/GameConfig.cs` 또는 아래 위치에 표시해 두었습니다. 기획서에서 결정되면 해당 값만 바꾸면 됩니다.

## B. 임시로 정한 값 ([가정])

**전투 · 덱**
- 같은 속성·랭크 카드 1장씩 → 5속성 × 13 = 65장 (21장의 "65장 덱" 언급과 일치)
- ~~5속성과 메인 속성은 플레이어가 직접 선택~~ → **[사용자 결정 2026-11-14]** 스테이지 진입 시 시스템이 7속성 중 5개와 메인 속성을 무작위로 정하고, 전투 전 5초 동안 공개 화면으로 보여 줌 (`StageSetup.CreateRandom`). 편성 화면 삭제
- [가정] 패배 후 재도전도 '스테이지 진입'으로 보고 속성을 새로 뽑음
- 제출한 카드 전체를 하나의 조합으로 판정, 족보에 안 쓰인 카드(키커)도 묘지로. 부분집합 자동 선택은 안 함
- ~~보충 드로우 시점: 플레이어 공격 직후~~ → v1.2 [확정]: 플레이어 턴 종료 (D장)
- 덱이 비면 묘지를 섞어서 덱으로 되돌림. 단, 방금 낸 카드는 섞이지 않음
- 묘지 정렬: 속성 순 → 랭크 순
- 동시 도착 시 플레이어 우선 행동

**능력치**
- 플레이어 SPD 100 (HP·DEF는 v1.2에서 200 / 10으로 [확정], D장)
- 에너미 SPD 90, 보스 SPD 105
- 층당 성장: HP +10%, ATK +8%, DEF +2(덧셈). 보스 HP ×2.5, ATK ×1.3
- 스테이지마다 플레이어 HP 전부 회복 (10.2 유지 범위 미정)

**에너미 행동**
- 스킬 공격 = ATK × 1.5
- DEF 증가량 = 층 수 (1~10)
- 등급별 가중치·비공격 후보는 v1.2에서 변경 (D장)

**속성 세부**
- 화상 1회분 = floor(최종 피해 × 0.3C ÷ 2). 같은 세기의 재적용은 갱신(2회로 교체)
- 금: 같거나 약한 연속 금 공격, 또는 적 턴이 지난 뒤의 금 공격은 기존 방깎을 해제하고 원본 DEF에 새로 적용
- 금: 적 턴이 지난 뒤의 비금 공격도 방깎을 해제 (적 턴 후 자동 만료 여부 미정이라 연속 행동 규칙과 동일하게 처리)
- 토 쉴드: 부여된 턴은 차감하지 않고, 이후 플레이어 턴 종료 2회 뒤 만료
- 일 속성 + True Damage 족보: 일 추가 피해(350 × 0.3C)는 DEF가 적용되는 일반 피해로 별도 계산
- 재도전: 패배 시 같은 층을 다시 시작

## D. 기획서 v1.2 반영 (2026-11-14)

**[확정] 기획서 내용**
- 턴 종료 버리기: 공격 처리(연출 포함) 후 '버릴 카드 선택' 단계. 손패 클릭으로 최대 2장 표시(다시 누르면 해제), '턴 종료'로 확정, 0장 가능
- 처리 순서: 버림 → (사용 + 버린 장수)만큼 보충 → 사용·버린 카드 모두 묘지로. 방금 쓴 카드와 버린 카드는 보충 중 재섞기에 섞이지 않음
- 보충 시점 = 플레이어 턴 종료. 교체 턴·처치 턴에는 버리기 단계 없음. CTB 행동 비용 변화 없음, 연속 행동 시 행동마다 버리기 단계
- 플레이어 초기 능력치: 최대 HP 200, DEF 10
- 스테이지 클리어마다 스탯 포인트 1점. 1포인트당 최대 체력 +10 / 속도 +5 / 카드 추가 드로우 확률 +5%p / 방어력 +3 / 데미지 증가 +2%
- 카드 추가 드로우: 보충 드로우 시 확률에 따라 1장 더. 손패 최대 장수 제한 없음
- 에너미 등급: 10의 배수 층 보스, 그 외 5의 배수 층(5, 15, 25…) 엘리트, 나머지 일반
- 일반 에너미는 디버프 제거·자기 버프 불가. 엘리트·보스만 디버프 제거와 자기 버프(ATK 증가·치명타율 증가)
- 치명타가 발동한 공격은 150% 피해

**[가정] 미정 항목에 넣은 임시값 (사용자 지정)**
- SPD 100 유지
- 데미지 증가: 최종 피해 × (1 + 2% × 포인트). 메인 +20%와 합연산하지 않는 별도 배율, DEF 경감 전에 적용. True Damage에도 적용, 화상량도 이 최종 피해 기준
- 포인트: 미사용 보유 가능(**[사용자 결정 2026-11-14] 쓰지 않은 포인트는 계속 누적** — 결과 화면에 보유 합계 표시), +/−로 배분 후 '확정'하면 되돌릴 수 없음, 패배 후 재도전해도 유지, 새로하기 시 초기화, PlayerPrefs 저장, 한 층의 포인트는 처음 클리어할 때 한 번만. 스탯 상한 없음
- 엘리트 배율 HP ×1.6, ATK ×1.15 (보스는 ×2.5, ×1.3 유지)
- 일반 에너미 비공격: 회복(HP 70% 미만일 때), DEF 증가만. 가중치 55 / 30 / 15 유지
- 엘리트·보스 가중치 45 / 30 / 25. 비공격 후보: 디버프 제거(디버프가 있을 때만), 회복, DEF 증가, ATK 증가, 치명타율 증가
- 치명타율: 기본 0%, 증가 1회당 +15%p, 최대 60%. ATK 증가는 1회당 현재 ATK의 +10%. 두 버프 모두 전투 끝까지 유지·누적
- 치명타 계산: 원 피해 × 1.5 → 플레이어 DEF 경감 → 쉴드 흡수 = floor(원 피해 × 1.5 × 100 / (100 + DEF)). 플레이어 치명타 없음
- 자동 플레이 버리기: 짝 없는 카드 중 낮은 랭크부터 최대 2장

**[가정] 구현하면서 Claude Code가 정한 세부 (확인 필요)**
- 엘리트 SPD = 일반 에너미와 같은 90 (보스만 105) → **[사용자 결정 2026-11-14] 확정**
- 치명타율이 최대(60%)면 '치명타율 증가'를 비공격 후보에서 뺌 (효과 없는 행동 방지) → **[사용자 결정 2026-11-14] 확정**
- 엘리트·보스의 '회복'도 일반과 같이 HP 70% 미만일 때만 후보 → **[사용자 결정 2026-11-14] 확정**
- 추가 드로우·치명타 판정은 확률이 0이면 난수를 쓰지 않음 (같은 시드의 기존 전투 재현 유지)
- 에너미 이름은 "N층 에너미"로 통일하고 화면에서 [엘리트]·[보스]를 앞에 붙임

## E. 기획서 v1.3 반영 (2026-11-14)

**[확정] 기획서 내용**
- 스탯 포인트: 일반 층 클리어 1점, 엘리트(5의 배수, 보스층 제외) 처치 2점, 보스(10의 배수) 처치 3점. 같은 층은 처음 클리어할 때 한 번만
- 투자 비용: 같은 스탯을 N레벨로 올리는 데 N점 (1레벨 1점, 2레벨 2점…)
- 투자 스탯 6개: 최대 체력 +10 / 속도 +5 / 카드 추가 드로우 +5%p → **+4%p (사용자 결정 2026-11-14)** / 방어력 +3 / 데미지 증가 +2% / 치명타율 +5%p (1레벨당)
- 플레이어 치명타 발동 시 150% 피해 (v1.2의 '플레이어 치명타 없음' 취소)
- 손패 최대 10장. 순서: 공격 → 버릴 카드 선택(최대 2장) → 보충 → 추가 드로우 판정 → 10장 초과 시 강제 버리기(넘는 장수, 2장 한도와 별개, 보충 없음, 묘지로) → 턴 종료 처리

**[가정] (사용자 지정)**
- 투자 비용은 스탯마다 따로 셈 (체력 3레벨이어도 속도 1레벨은 1점)
- 치명타 판정은 공격 1회당 1번, 최종 피해 전체(일반 + True)에 × 1.5, 데미지 증가와 곱함, 화상량은 치명타 반영 후 기준, 교체 턴에는 판정 안 함, 상한 100%, 전투 시드 RNG 사용
- 자동 플레이 강제 버리기도 '짝 없는 낮은 랭크부터' (모자라면 남은 카드 중 낮은 랭크부터)

**[가정] Claude Code가 정한 세부 (확인 필요)**
- 치명타 배율은 DEF 경감 전에 곱함 (데미지 증가와 같은 위치) → **[사용자 결정 2026-11-14] 확정** (데미지 증가 위치도 확정). 화상 틱에는 치명타 판정 없음 (화상량은 지금처럼 치명타 반영 후 피해 기준)
- 치명타율 0이면 난수를 쓰지 않음 (기존 시드 재현 유지)
- 예전 저장(v1.2, 값 = 포인트)은 그대로 레벨로 읽음 → v1.2 때 투자한 레벨은 새 비용 규칙으로 다시 계산하지 않음 → **[사용자 결정 2026-11-14] 확정**

**스테이지 진입 (사용자 결정 2026-11-14)**: 시스템이 5속성·메인 속성을 무작위로 정하고 공개 화면 5초(클릭하면 바로 시작). 편성 화면 삭제

## C. 검증 결과

- 기획서 QA 기대값 25개를 독립 구현(Python)으로 검산 → 전부 일치 (QA-DMG-01~08, QA-GOLD-01·02, QA-ATTR-04 등)
- 같은 항목을 Unity EditMode 테스트로 옮김 (`Tests/Editor/RuleTests.cs`, 22개 테스트)
- v1.2 테스트 21개 추가 (`Tests/Editor/RuleTestsV12.cs`) — Unity에서 43개 전부 통과 (2026-11-14)
- 손패 탐색: 새 방식(족보별 후보)이 기존 전수 탐색과 같은 최고 점수를 내는지 7장 손패 3,000개 · 20장 손패 20개로 대조 → 전부 일치. 20장 손패 200개 탐색 약 40ms
- 21장 검증 과제 "FULL HOUSE가 FLUSH보다 잘 나오는가" → **맞음.** 첫 7장에서 낼 수 있는 확률은 FULL HOUSE 3.35%, FLUSH 1.12%, STRAIGHT 4.50% (N=20,000). 현재 족보 순서(STRAIGHT < FULL HOUSE < FLUSH)는 확률 순서와 일치
- ROYAL FLUSH와 PENTAGRAM은 첫 7장 기준 20,000회 중 0회. 실제 출현은 여러 턴에 걸쳐 모아야 가능
